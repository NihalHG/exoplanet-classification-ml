# 🪐 Exoplanet Candidate Classification Using Machine Learning

An exploratory machine learning project using data from NASA's Kepler mission to study the classification of exoplanet candidates.

## 🔭 Overview

The Kepler mission collected observations of stars to identify signals that may indicate the presence of exoplanets. This project explores how machine learning can distinguish exoplanet candidate outcomes using data from the **Kepler Objects of Interest (KOI)** dataset.

The focus is on understanding the data, building classification models, evaluating their performance, and interpreting their limitations.

## 🎯 Objectives

- Explore and understand the dataset using Python.
- Perform data cleaning and exploratory data analysis (EDA).
- Develop a baseline classification model.
- Compare suitable machine learning algorithms.
- Evaluate models using appropriate classification metrics.
- Investigate model errors, feature relevance, and potential data leakage.

## 🛰️ Dataset
